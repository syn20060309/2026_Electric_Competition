# MSPM0G3507 八路灰度巡线小车

本工程通过八路灰度模块检测黑线，并使用四路电机驱动板控制小车巡线。

## 使用方法

- 上电后电机保持停止。
- 短按或长按 K1 可切换巡线启停状态。
- 启动后，主循环持续调用 `LineWalking()` 完成巡线。

## 硬件连接

### 八路灰度模块

| 模块 | MSPM0G3507 | 作用 |
| --- | --- | --- |
| VCC | 5V | 供电 |
| GND | GND | 共地 |
| SDA | PA16 / I2C1 SDA | 数据 |
| SCL | PA15 / I2C1 SCL | 时钟 |

模块地址为 `0x12`。

### 四路电机驱动板

| 驱动板 | MSPM0G3507 | 信号方向 |
| --- | --- | --- |
| 5V | 5V | 扩展板到驱动板 |
| GND | GND | 共地 |
| TX2 | PB7 / UART1 RX | 驱动板到 MSPM0 |
| RX2 | PB6 / UART1 TX | MSPM0 到驱动板 |

通信波特率为 `115200`，电机类型配置为 L 型 520 电机。

### 按键

K1 使用 PA2，按下后切换巡线启停状态。

### 调试串口

调试串口波特率为 `115200`：

| USB 转串口 | MSPM0G3507 |
| --- | --- |
| RX | PA10 / UART0 TX |
| TX | PA11 / UART0 RX |
| GND | GND |
