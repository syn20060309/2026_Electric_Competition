# MSPM0G3507 巡线小车工程

## 工程完成的任务

本工程使用四路电机驱动板的编码器里程、MPU6050 航向角和八路灰度模块完成小车运动控制。当前代码包含 4 个任务：

1. 保持初始航向直行，越过白色区域后检测到黑线并停车。
2. 直行穿过场地，结合灰度巡线完成一次往返。
3. 按设定航向斜向穿越，结合灰度巡线完成路线。
4. 在任务 3 路线基础上连续运行 4 圈，并按圈数补偿航向误差。

K1 长按依次选择任务 1～4，蜂鸣器鸣叫次数表示当前任务编号；短按启动已选择的任务，再次长按可停车并切换到下一任务。

## 硬件接线

### 1. 八路灰度巡线模块

使用扩展板上标有 **IIC1 / 八路巡线模块接口** 的插座。该接口与工程中的硬件 I2C1 配置一致。

| 八路灰度模块 | 扩展板 / MSPM0G3507 | 作用 |
| --- | --- | --- |
| VCC | 5V | 模块供电 |
| GND | GND | 共地 |
| SDA | IIC1 SDA / PA16 | I2C1 数据线 |
| SCL | IIC1 SCL / PA15 | I2C1 时钟线 |

工程使用的八路灰度模块 I2C 地址为 `0x12`。

### 2. 四路电机驱动板

使用扩展板上标有 **Uart1 / 四路电机驱动板接口** 的插座。串口收发线已经按通信方向交叉：

| 四路电机驱动板 | 扩展板 / MSPM0G3507 | 信号方向 |
| --- | --- | --- |
| 5V | 5V | 扩展板 → 驱动板 |
| GND | GND | 必须共地 |
| TX2 | UART1 RX / PB7 | 驱动板 → MSPM0 |
| RX2 | UART1 TX / PB6 | MSPM0 → 驱动板 |

该串口在工程中命名为 `Motor`，波特率为 `115200`。代码将电机类型设置为 **L 型 520 电机**（`MOTOR_TYPE = 5`）。

### 3. MPU6050

工程使用 GPIO 模拟 I2C 连接 MPU6050：

| MPU6050 | MSPM0G3507 | 作用 |
| --- | --- | --- |
| SDA | PA0 | 模拟 I2C 数据线 |
| SCL | PA1 | 模拟 I2C 时钟线 |
| AD0 | GND | 选择代码使用的 `0x68` 地址 |
| GND | GND | 共地 |

> 随工程提供的扩展板资料没有标出 MPU6050 专用插座，也没有注明所用 MPU6050 模块型号和供电电压。因此这里不推测 VCC 应接 3.3V 还是 5V；请按实际模块丝印或该模块说明书供电。PA0、PA1 和 AD0 接法由当前工程配置及代码确认。

### 4. 调试串口（可选）

工程还配置了一个 `115200` 波特率的打印 / 接收串口：

| USB 转串口 | MSPM0G3507 | 信号方向 |
| --- | --- | --- |
| RX | PA10（UART0 TX） | MSPM0 → USB 转串口 |
| TX | PA11（UART0 RX） | USB 转串口 → MSPM0 |
| GND | GND | 必须共地 |

> 扩展板速查表中的普通 **Uart1 串口接口** 对应 PA8 / PA9，与本工程配置的 PA10 / PA11 不一致，不能直接按该插座接调试串口。需要从核心板 GPIO 排针引出 PA10、PA11。

## 扩展板上的板载资源

这些资源已经连接在扩展板或核心板上，一般不需要额外接线：

| 资源 | MSPM0G3507 引脚 | 工程用途 |
| --- | --- | --- |
| 自定义按键 K1 | PA2 | 长按选择任务，短按启动 |
| 蜂鸣器 | PB24 | 初始化提示、任务编号和过线提示 |
| LED D1 | PB2 | 随蜂鸣器提示 |
| LED D2 | PB3 | 上电初始化完成提示 |

扩展板输入电源接口标注为 **IN 5–12V**。接线或插拔模块前应先断电，并确认开发板朝向正确。

## 接线核对要点

- 所有外接模块必须与 MSPM0 扩展板共地。
- 电机串口是 `PB6(TX) → 驱动板 RX2`、`驱动板 TX2 → PB7(RX)`，不要接成 TX 对 TX。
- 八路灰度必须接扩展板的 **IIC1** 接口，不是旁边的 IIC 或 IIC0 接口。
- MPU6050 使用 PA0 / PA1 软件 I2C；八路灰度使用 PA16 / PA15 硬件 I2C，两组信号不要混接。
- 调试串口使用 PA10 / PA11，不对应扩展板速查表中的 PA8 / PA9 普通串口插座。
